# Ч1. Движения человека: свой скелет, клипы из разрешённых баз, склейка и смешивание

Сначала прочитай `docs/tasks/_common.md` (общие правила, они действуют и здесь), `docs/ARCHITECTURE.md` **6.4** (семейство `Biped`, кости по стандарту VRM, клипы переносятся на скелет семейства) и раздел про лицензии. Рабочая папка: `/Users/baies/studio-wt/H1-human-motion`, порт e2e **5208**.

## Идея (решение владельца 21.11)
Скелет — **наш**, по стандарту костей VRM-гуманоида. Из открытых баз берём только записи движений (повороты суставов по кадрам) и переносим их на наш скелет. Из готовых клипов собираем **новые движения**: склейка с плавными переходами, смешивание по весу, слой верха тела поверх походки, ноги прилипают к земле. Потом (Ч2) — человечек и ролик на минуту. Эмоции лица — позже, не здесь.

## Объём
1. **Скелет `Biped`** (логика в `components`, без three): кости VRM-гуманоида (hips, spine, chest, neck, head, плечи, руки, кисти, ноги, стопы, пальцы ног; пальцы рук — по желанию), пропорции — параметры (рост, длина ног и рук, ширина плеч). Своя математика кватернионов в `components` (three там нельзя).
2. **Чтение BVH и перенос на наш скелет** (скрипт в `scripts/`, запускается вручную, не в рантайме): выравнивание поз покоя (T/A-поза), повороты суставов в локальных осях нашего скелета, движение корня масштабируется по длине ног. Результат — наш формат клипа: частота, кости, кватернионы, корень.
3. **Сборка новых движений** (чистые функции от t, детерминированно, seek = проигрывание):
   - склейка A → B с переходом N кадров; корень и курс не прыгают;
   - смешивание по весу (шаг медленный ↔ быстрый, два стиля 100STYLE);
   - слой верха тела поверх походки (оглянуться на ходу, руки вверх при удивлении);
   - ноги к земле: стопа не скользит, стоит на `ctx.heightAt` (IK двух костей);
   - «удивление телом» без готового клипа: шёл → замедлился → замер → отшатнулся (корпус назад, плечи вверх, руки к груди) → огляделся. Склейка готовых кусков плюс процедурный слой.
4. **Компонент** `Biped` (версия, схема, пресеты): ручки — `clip`, `speed`, `style` (вес смешивания), `lookAt`; поведения — `walkTo({x,z})`, `stop()`, `startle()`, `lookAround()`.
5. **Витрина** `library.html?object=Biped`: **скелет** (кости палочками и суставы шариками, свой вид в `render-three/views/`, без чужих моделей), список клипов, ползунки смешивания, кнопки склейки, тень на земле. Демо: удивление из пункта 3.

## НЕ входит
Тело и внешность человечка, ролик на минуту (это Ч2), лицо и эмоции, робот (он уже есть, не трогать).

## Приёмка (сверх общей)
- Кадры в `artifacts/H1/`: скелет в позе покоя спереди и сбоку; по 3 клипа из каждой базы сериями по 6 кадров; склейка шаг → бег; смешивание двух стилей (вес 0 / 0.5 / 1); удивление сериями по 8 кадров.
- Тест «стопа не скользит»: в фазе опоры смещение стопы ≤ 1 см.
- Тест seek: случайный порядок перемоток совпадает с проигрыванием.
- Таблица отобранных клипов: имя, база, исходный файл, лицензия, длительность.
- Честно: какие движения выглядят неестественно и почему.
