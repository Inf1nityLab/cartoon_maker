# Опись объектов из четырёх демо → наши семейства (18.11)

Правило: из каждого демо берём **лучшее** для каждого объекта. Код — только из MIT (лес nanites, ez-tree, threejs-water); из duck-days, oasis и океана (лицензии нет) — только приёмы, код пишем свой (`docs/tasks/_common.md`).

## Что есть в каждом демо

| Демо | Файлы | Объекты |
|---|---|---|
| **Лес** (threejs-nanites, MIT) | `src/trees.ts`, `forest/`, `grass*.ts`, `ground/`, `road*.ts`, `clouds.ts`, `godrays.ts`, `lighting.ts`, `autumn*.ts` | деревья и кусты (ez-tree), лес на миллион деревьев, трава, земля (почва, подстилка из листьев, брусчатка), дорога, облака, солнечные лучи, туман, осень |
| **Океан** (PELAGIC, без лицензии) | `wave-spectrum.js`, `wave-model.js`, `foam.js`, `caustics.js`, `shaders.js` | океанские волны по спектру, пена на гребнях, блики на гребнях, прозрачное мелководье над песком, световая рябь (каустики) на дне |
| **Оазис** (без лицензии) | `water.ts`, `terrain.ts`, `heightfield.ts`, `duneshadow.ts`, `palms.ts`, `plants.ts`, `sky.ts`, `post.ts`, `camera.ts` | вода оазиса, дюны и их тени, пальмы, пустынные растения, время суток (пресеты), цветокоррекция и зерно плёнки, 6 пролётов камеры-дрона |
| **Пруд с уткой** (duck-days; без лицензии, кроме `third_party/threejs-water` — MIT) | `water/` (+ `third_party/threejs-water`), `world/Terrain.ts`, `Trees.ts`, `Vegetation.ts`, `LilyCove.ts`, `Props.ts`, `Wildlife.ts`, `Particles.ts`, `Sky.ts`, `duck/` | вода пруда с преломлением и каустиками, подводный мир (лучи, мутность), чаша пруда и берег, ива и деревья, камыш, рогоз, травы, папоротник, лютики, дербенник, рдест (подводная трава), кувшинки, камни, бревно, затонувшая ветка, рыбы, стрекозы, частицы (пыльца/блики), утка с процедурной анимацией |
